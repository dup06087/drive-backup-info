앱의 용도와 접근 범위

주식 데이터 백업은 운영자의 개인용 시장 데이터 백업 도구입니다. Google Drive 연결 시 파일 조회·읽기·쓰기에 필요한 권한을 요청합니다. 실제 자동 작업은 운영자가 지정한 백업 폴더에서 파일 저장, 목록 조회 및 무결성 검사에 사용합니다.

사용하고 보관하는 정보

연결을 유지하기 위한 OAuth 액세스 토큰과 갱신 토큰을 운영자가 관리하는 서버의 접근 제한 설정 파일에 저장합니다. 지정 폴더의 파일명, 파일 식별자, 크기 등 메타데이터와 백업 파일을 처리할 수 있습니다. Google 계정 비밀번호를 수집하거나 저장하지 않습니다.

이용 목적과 외부 처리

Google API를 통해 접근한 정보는 백업 운영과 무결성 확인에 사용합니다. 광고, 판매 또는 AI 모델 학습 목적으로 사용하지 않습니다. 운영자가 관리하는 Oracle Cloud 서버와 Google Drive가 백업 작업에 사용됩니다. 별도로 수집한 시장 데이터의 원본과 변환 결과, 백업 파일 목록·해시·전송 검증 기록은 운영자가 지정한 GitHub 저장소에 보관할 수 있습니다. Google OAuth 인증 토큰은 해당 저장소에 게시하지 않습니다.

보관과 연결 해제

백업 파일은 운영자가 삭제할 때까지 보관합니다. 무결성 확인을 위해 서버에 임시로 내려받은 검사 파일은 검사가 끝나면 삭제합니다. 계정 소유자는 Google 계정의 연결 관리에서 접근 권한을 취소할 수 있습니다. 권한 취소만으로 기존 백업 파일이 자동 삭제되지는 않으며, 남은 파일과 서버 설정의 삭제는 운영자가 관리합니다.
